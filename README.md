# designmonks.co — Crawl Status Tracker

Live page: **https://aouwalitshikkha.github.io/designmonks-crawl-status/**

Crawl/index status tracker for [designmonks.co](https://www.designmonks.co). No API &mdash; inventory from XML sitemap + GSC. Columns: URL, type, status (no last-update date column by request). Updated daily in background via cron.
